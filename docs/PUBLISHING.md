# GitHub and DOI

1. Supply the destination GitHub repository and verify public-sharing permission for participant-level data.
2. Review files, choose licenses with the rights holder, and commit only this package. Do not commit the parent workspace or private review directory.
3. Upload the reviewed package to the selected repository and create a versioned release.
4. Connect the repository to Zenodo before creating the release, or upload a release archive manually to Zenodo. Complete metadata and publish the record to obtain a DOI.
5. Cite the version DOI and GitHub repository in the manuscript. Never substitute a GitHub URL or commit hash for a DOI.

Official instructions: https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content
